# Лабораторная работа 1 — Цветовые модели
# 实验作业一 — 颜色模型交互式转换器

Интерактивное веб-приложение для работы с цветовыми моделями: **RGB, CMYK, HSV, HLS, XYZ, LAB**.
一个交互式网页应用，用于处理颜色模型 RGB / CMYK / HSV / HLS / XYZ / LAB。

---

## 1. Описание / 项目简介

Приложение позволяет пользователю задавать цвет и одновременно наблюдать его представление
в **трёх** цветовых моделях. При изменении любой компоненты все остальные модели
пересчитываются автоматически. Некорректные значения (выход за границы модели) обрезаются
с выводом ненавязчивого предупреждения.

应用允许用户设定颜色，并同时查看其在**三种**颜色模型下的表示；修改任一分量，其余模型自动重算；
当出现越界值（如 XYZ/LAB 转回 RGB 超出范围）时会裁剪并给出提示。

## 2. Как запустить / 运行方式

Откройте файл `index.html` в любом браузере (Chrome / Edge / Firefox). Приложение полностью
автономно (HTML + CSS + JavaScript), установка и сборка не требуются.

直接用任意浏览器打开 `index.html` 即可运行，纯前端单文件，无需安装或编译。
（如需 `.exe`：用 Electron / NW.js 打包 `index.html`，或部署到任意静态托管即可作为“公开的网页应用”提交。）

## 3. Возможности / 功能对照作业要求

| Требование задания | Реализация |
|---|---|
| Задание точного цвета (поля ввода) | 每个分量提供数字输入框 |
| Выбор цвета из палитры | 顶部颜色选择器 `input type=color` |

## 4. Цветовые формулы / 颜色转换公式

- **HSV / HLS**：标准 HSL/HSV ↔ RGB 公式。
- **CMYK**：`K = 1 − max(R,G,B)`，`C/M/Y = (1 − R/G/B − K)/(1 − K)`；反向 `R = (1−C)(1−K)`。
- **XYZ (D65)**：sRGB 经伽马线性化后乘以 sRGB→XYZ 矩阵（白点 D65）。
- **LAB (D65)**：由 XYZ 经 `f(t)=t^{1/3} (t>0.008856)` 转换，白点 `Xn=95.047, Yn=100, Zn=108.883`。
- 反向转换使用对应逆公式；XYZ/LAB → RGB 越界时裁剪并提示。

在应用顶部下拉框选择自己的变体号，对应三种模型会自动载入。
